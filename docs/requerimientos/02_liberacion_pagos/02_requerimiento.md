# Liberacion de pagos

Luego de la aprobación de orden de pago se requiere que se liberen todas las facturas o boletas en el sistema SAP.
Para ello el equipo SAP me ha entregado un API para realizar esa acción. La especificacion del API esta en ServicioLiberacionPagos.pdf

Considerar que en una Orden de Pago puede haber varias facturas.

Analisar este requerimiento y entregarle una propuesta de solución.
